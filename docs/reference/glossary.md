# Glossary

| Term | Definition |
|---|---|
| Channel | A logical or allocated communication resource used to characterize or constrain traffic, according to the applicable service definition. |
| Convergence Sublayer | Functions that adapt or supplement a data-link technology so that required Subnetwork capabilities can be exposed. |
| Layer | An architectural subdivision that provides services to users above it and relies on services below it. |
| Maximum Transmission Unit (MTU) | Maximum data-unit size accepted for transfer by a service or protocol at the specified boundary. |
| Node | A networked entity with an address; exact terminology follows the referenced networking specification. |
| Packet Data Unit (PDU) | A protocol data unit containing control information and, where applicable, user data. |
| Priority | A parameter used to determine the relative precedence of one SDU or traffic flow over another. |
| Quality of Service (QoS) | Communication characteristics used to describe the service provided, such as reliability, throughput, latency, or delivery behavior. |
| Service | A capability provided by a layer, together with the lower layers on which it relies, to service users. |
| Service Access Point (SAP) | An abstract point at which a service is made available to a service user. |
| Service Data Unit (SDU) | Information passed across a service interface or delivered by that interface. |
| Subnetwork | A bounded collection of interconnected nodes and communication elements, as defined by the applicable networking model. |

Definitions are concise working descriptions. Where a term has a formal CCSDS definition, the normative publication takes precedence.
